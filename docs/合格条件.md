# 合格条件 — 人間が見て良い編集であること

**このファイルが、成果物の合否を決める唯一の正である。**

マスター指示（2026-08-19）：
> すべて共通は人間様が見て良い編集成果物であること。だ。
> 内部がどうでも再現性高く人間様が見て良い編集なら何だっていいし、
> 人間が見てダメなら内部が完璧でも意味がない。

したがって判定は**動画を見て行う**。コードの内部状態・中間ファイル・ログは合否の根拠にしない。
各項目は動画を1本通しで再生すれば YES/NO で答えられる形にしてある。主観的な項目は置かない。
**1つでも NO があれば不合格。**

切り方の物理（どこにハサミを入れるか）は `docs/編集についての虎の巻.md` が正。
このファイルはその上位層＝**何を作れば人間が納得するか**を定める。

## 0. 全モード共通のチェックリスト

1人語り・対談を問わず、出力した動画すべてに適用する。

| # | 質問（YES/NO） |
|---|---|
| 1 | 冒頭30秒以内に、この動画が何に答えるのかを述べる発話が**実際に存在する**か |
| 2 | 冒頭で提示された問い・約束に対応する**答えの発話が後半に存在する**か（問いと答えを1組ずつ指させるか） |
| 3 | 最後のカットが**言い切りの文末**で終わっているか（語尾の途中・助詞終わり・AIが作った体言止めで終わっていない） |
| 4 | すべてのカットの冒頭が、助詞・接続詞・指示語で始まっていないか（1箇所でもあれば NO） |
| 5 | 動画内のすべての指示語（「これ」「さっきの」「その方法」）について、**指す先の発話が動画内に存在する**か |
| 6 | 説明の順序が入れ替わっていないか（ある用語・前提が、それを説明する箇所より前で当然のように使われている箇所がゼロか） |
| 7 | **言いかけて終わっている話題がゼロ**か（始まったが結論に到達せず次の話題に移る箇所が無い） |
| 8 | 間の長さが場所によって変わっているか（話題の変わり目の間が文中の間より明らかに長い。全部同じ長さなら NO） |
| 9 | つなぎ目にプツッというノイズ・完全な無音の断絶・喋りの頭切れ／尻切れが1箇所も無いか |
| 10 | すべてのテロップが消えるまでに読み切れるか（4文字/秒より速く消えるテロップがゼロ）。画面外・重なり・口元への被りが無いか |

**絶対禁止（1つでも該当したら他が全て YES でも不合格）**

> 原動画における表現の**意図や趣旨を改変し、誤解を生じる内容とすること**。

日本の切り抜きガイドライン3社（ドズル社・アツクラ・幕末志士）が独立に同一の条項を持ち、
日本ファクトチェックセンターも「問題は切り取りで**発言の意味が変わるか**」と定義している。
学術的には contextomy。過ちは切り抜くこと自体ではなく、
**「話者の意図を明らかにしている近傍の語句を落としたこと」**である。
＝これが「範囲をどこまで広げるか」の停止条件になる。

本人が言っていない文を継ぎ接ぎで作ること（frankenbite）は論外。
順序の入れ替えは「意味が変わらない」場合のみ可。
**そのために、元の連続した音声を再生できる導線を必ず用意する**（人間が項目を判定できなくなるため）。

## 1. ダイジェスト

### 定義（これを外すと、そもそもダイジェストではない）

業界では**別カテゴリの製品**として分かれている。混同が「切れていない」という評価の直接原因だった。

- **抽出型** — 山場を数本選んで繋ぐ（Opus Clip / Klap / Descript）＝**これがダイジェスト**
- **短縮型** — 連続タイムラインから無音・言い淀みを間引く（Vrew）＝**これは無音カット**

### 尺 — 決めない。比率も置かない（マスター判断 2026-08-19）

**長さの目標を置いてはいけない。比率の上限も置かない。この節に数字を書き足してはいけない。**

調査では業界・学術とも「元尺の2〜15%」という数字が揃った。**これを採用しない。**
理由は2つある。

**1. 比率は素材の長さに対して不変ではない。**
根拠として挙がった事例は、元素材が 90分・60分・3時間・120分 のものばかりだった。
同じ比率を3分の素材に当てれば 30秒 になる。**3分のダイジェストが30秒になるはずがない。**
長い素材で成り立つ比率を短い素材に持ち込むこと自体が誤りだった。

**2. 数字を与えると、AI はその数字に合わせて内容を捨てる。**
実測で確認した。15%/30% を目標として与えたところ、AI はその数字に収めるために
「3つ紹介します」の約束を回収せず1つで打ち切った。
**「目標の尺」を削除したときと同じ失敗を、比率という別の数字で再発させた。**

> ほぼ本題で構成されている素材は、ダイジェストといった時点で破綻する。時間制限は不要。
> **背骨部分だけで、一番おいしい部分だけで構成されているのがダイジェストだ。**

判定は**内容で行う**。「背骨と山場だけが残っているか」であって「何%に縮んだか」ではない。
**背骨と山場だけを選んだ結果が何秒になっても、それが正しい長さ。**
素材がほぼ本題だけで構成されているなら、ほとんど縮まないのが正しい。

### 構成

**均等に間引くことを支持する資料は1件も見つからなかった。** 選ぶのであって間引くのではない。

```
フック  = 結論そのもの。動画中で最も強い一文を、時系列を無視して先頭に置く
本体    = それ単体で意味が通るブロック（個数も長さも決めない。背骨が要る数だけ）
締め    = 持ち帰るもの
```

**時系列は守らなくてよい**（ダイジェストは recap ではない）。ただし因果関係
（Aの説明がBの前提）が壊れる並べ替えは禁止。

**必ず捨てる（優先度順）**：挨拶 → 自己紹介 → 前置き → 本題から逸れた余談 → 繰り返し → 言い淀み → 長い間
**必ず残す**：結論となる主張 / 転換点 / 感情のピーク

### 追加チェック

| # | 質問（YES/NO） |
|---|---|
| D1 | **背骨と山場だけで構成されているか**（残った区間のどれかが「これは無くてもいい」と言えるなら NO） |
| D2 | 冒頭3秒に、動画中で最も強い主張が置かれているか（挨拶・前置きで始まっていない） |
| D3 | 本体の各ブロックが、それ単体で意味が通るか |
| D4 | 締めがあるか（最後のカットの直後に唐突に映像が止まっていない） |

## 2. 話題で分ける

### 前提（これを外すと設計を誤る）

**人間どうしでも話題の切れ目は一致しない。技術の問題ではなく対象の性質である。**

- 大場・中井 2020：日本語10分の会話を学部生40名が区分 → **区分数は最少7〜最多50**。
  大話題に至っては **12名が1つも区切らなかった**
- Hearst 1997：英語記事、7名で κ=0.647。「真の境界」の定義は**7人中3人以上が一致した点**
- CSJ：3名で作業し、**一致率の低い20講演を分析対象から除外**して公開した

→ **「唯一の正解」を当てにいく設計は原理的に破綻する。** 目指すのは
「複数の人間が支持しうる境界を出す」ことと「明らかにおかしい境界を出さない」ことの2つ。
実際、AssemblyAI と Descript は自動判定を諦めて**粒度をユーザーが指定する設計**に寄せている。

### 日本語で実際に効く手がかり（実測・重み付き）

日本語母語話者20名がリアルタイムで「話題が変わった」と判断した実験（趙・巽 2025）の GLMM 推定値。

| 手がかり | 係数 | 有意 |
|---|---|---|
| **新情報**（直近に出ていない名詞の登場） | **+1.317** | p<0.001 |
| **質問表現** | **+0.893** | p<0.001 |
| **沈黙（1秒以上）** | **+0.737** | p<0.05 |
| **笑い** | **+0.402** | p<0.05 |
| 談話標識（さて・ところで・じゃあ） | +0.206 | **有意でない** |
| あいづち | −0.363 | **負の傾向** |

**「さて」「ところで」等の接続詞リストで切るのは、日本語では人間の感覚と一致しない。**
中国語では有意だったが日本語では効かなかった。**あいづちが続く区間を境界にするのは逆効果。**

手がかりは足し算で効く。**単一の手がかりで切らず、複数手がかりの共起点を境界にする。**

### 1話題の長さ

**決めない。** 調査では「1〜3分」「下限2分」といった数字が出たが、いずれも
1時間級の講演・番組を前提にした値で、素材の長さに対して不変ではない（§1と同じ理由）。
話題の切れ目は話題の切れ目であって、長さで決まるものではない。

### 1本の話題動画の定義

> それまでと異なる対象・側面へ言及を始めた最初の発話（その直前の間の内側）から始まり、
> その話題に付けた題名「XのY」が答え切られた最後の文末までで終わる。
> 冒頭の挨拶・自己紹介と末尾の締めの挨拶は含めない。

### 追加チェック

| # | 質問（YES/NO） |
|---|---|
| T1 | この動画に、30字以内の「**〜の〜**」という題名を**1つだけ**付けられるか（2つ必要＝話題が混ざっている。付かない＝まとまりでない） |
| T2 | 本編の中に「あ、話が変わった」と感じる箇所が無いか |
| T3 | 主張だけでなく、理由・具体例・経緯のいずれかが最低1つ入っているか（独立した内容が2つ以上ある） |
| T5 | 切れ目が、**話者の交替・映像の切り替わり・逆接（でも/しかし）だけを理由に**置かれていないか |

題名の形式は CSJ に倣い「**X の Y**」。Y の候補：問題点／特徴／解釈／内容・状況／経緯／帰結・結論／理由／きっかけ／目的／まとめ／手法・手順。
例：「壁が薄いことの問題点」「編集を外注した経緯」。

**ショット境界＝話題境界ではない**（TRECVID が明記：1ショットの中に境界がありうるし、
1ストーリーが複数ショットにまたがる）。

## 3. 指定された話題だけを抽出する

### コールドオープンテスト

ミュートで初見の人が答えられるか。

1. 誰が話しているか
2. 何に反応しているか
3. 何が論点か
4. なぜ最初の3秒で気にすべきか
5. **その場で決着がつくか**

**Q1〜Q4 が NO ならテロップで救える。Q5 が NO ならテロップでは救えない — 範囲選定のやり直しである。**
この分岐が最も重要。

### 素材に無かったときの振る舞い

**近い区間で埋めて1本を必ず作ってはいけない。0件を返すか、部分一致である旨を明示する。**
業界でこれを公式に明文化しているのは Vizard.ai のみ：
「指示に厳密に整合するクリップが見つからなければ、クリップは返さない」。

**そして、これはプロンプトに書けば守られる類の要件ではない。**
Google Research の実測で、**大きいモデルほど根拠が不十分なとき棄権せず誤答する**ことが
確認されている。**「話題が無い素材」を固定素材として用意し、0件を返すことを実測でテストする。**

### 追加チェック

| # | 質問（YES/NO） |
|---|---|
| S1 | 冒頭2〜3秒で、指定した話題が何であるかが分かるか |
| S2 | 誰が話しているか分かるか |
| S3 | 指定した話題と**無関係な区間が1つも含まれていない**か |
| S4 | 元動画でその話題を語っている箇所のうち、**結論に必要な発言が落ちていない**か |
| S5 | 同じ内容が2回以上繰り返されていないか |
| S6 | 元の連続音声と並べて聞いたとき、**発言の意味が変わっていない**か |

S4 は他の指標では測れない（欠落は「事実として矛盾していない」ため見逃される）。
重要な発言を「絶対に落とせない／あってもなくても良い」に分け、**前者の取りこぼしだけを厳しく測る**。

## 4. 言い淀み（フィラー）の除去

### 2種類に分ける（難易度が1桁違う）

| | クラスA（母音性） | クラスB（語彙的） |
|---|---|---|
| 対象 | えー／あー／んー／うー／語尾の伸ばし | あの／その／まあ／なんか／こう／この／で・んで |
| 判定 | **音響だけで可能**（平坦に発話され、句頭の上昇もアクセント核も無い） | **文脈判断が必須** |
| 誤爆リスク | 低い | 高い（連体詞・副詞と同形） |
| 実装順序 | **先にこれだけ作る** | A が安定してから |

CSJ の実測分類では、えー系・え系だけで約58%。**クラスA だけで大半が取れる。**

### 自動判定が原理的に無理な部分がある

CSJ（国語研）転記仕様書の原文：

> 「あの／その」に関して、**フィラーと連体詞とで迷う場合には、原則(F)を付与した上で迷った旨をコメント**

専門の言語学者が音声を聞いた上で迷い、コメントを残す運用になっている。
**文脈なしの自動判定は原理的に無理**であることの一次証拠。
→ クラスB は既定で「提案のみ・承認制」。**迷ったら消さない**（虎の巻 §4-1）。

### 消してはいけないもの

- **感情表出系感動詞**（あーあ／うわ／えっ／ぎょっ）— これはフィラーではなく感情表現そのもの
- **応答詞**（はい／うん／ええ／いや）— CSJ は独話では応答詞に (F) を付けない
- **語尾の伸ばし**（「ですねー」の「ー」）— 消すと語が壊れる。短縮はしても削除はしない

### 消せないものは消さない

Descript の "Avoid harsh cuts" が実装している降参の選択肢：
**「隣の語を削らずには消せないフィラーは、消さない」**。
これが無いと「カットが harsh」という最多の不満（他要望より400票多い upvote）に直結する。

### 数値

- クロスフェード **5〜10ms**（長くすると語頭のアタックが痩せる）
- **0.2秒以上の途切れ＝ポーズ**（CSJ の転記単位認定基準）。文末形式の直後なら 0.05秒でも切れ目
- 無音カットの実務既定値：**0.75秒**（最短 0.3秒）＝ Premiere Pro
- **重要な発言の前後には 1〜2秒の間を戻す**（全部同じ長さにしない＝共通チェック項目8）

### ガード

- ひと塊の中でフィラー判定が**半数を超えたら、判定が壊れていると見なして全体を却下**
- 除去した区間のログを必ず残す（開始・終了時刻・語・判定理由・クラス）

## 5. 使い方

1. 出力ができたら、**まず動画を通しで1回見る**。
2. 共通チェックリスト（0章）10項目に YES/NO で答える。
3. モード別の追加チェックに答える。
4. **1つでも NO があれば不合格。** 内部の実装がどれだけ整っていても不合格。
5. 全部 YES なら合格。内部がどうなっていても合格。
