# 字幕校正の手順

## 位置づけ

1. 字幕ありジョブでは、字幕の生成と校正を render の前に必ず終える。
2. 校正の照合（`captions --check`）を通っていない字幕は、render で焼けない。
3. 時刻はプログラムの管理下に置く。校正で直すのは本文だけとする。
4. 決定的に直せる誤変換は、用語辞書（`video-shorts/src/term-corrections.json`）へ登録し、プログラムに直させる。
5. 意味レベルの修正は、証拠のある箇所だけに行う。推測で直さない。

## 生成

1. 編集案の承認後に、次のコマンドで字幕を生成する。

```
node src/edit-job.mjs captions <jobId>
```

2. 生成物は次の3点とする。
   - `captions.ass`（焼き込み用）
   - `captions.txt`（校正用一覧）
   - `captions.json`（生成の記録。編集案ハッシュと各字幕の時刻・文節範囲）
3. 編集案を変えたら、字幕を生成し直し、校正を最初からやり直す。

## 読み直し

1. `captions.txt` の全文を、最初から最後まで読む。
2. 話の流れを把握してから、字幕を1件ずつ見る。
3. 検証フラグ（`captions.txt` の末尾の一覧）の箇所は、必ず前後の文と一緒に見る。

## 修正

1. 同音異義語と漢字の誤りを、意味に照らして直す。
2. 固有名詞と専門用語は、用語リスト（`term-corrections.json` の登録内容と、台本案・指示に現れる表記）に合わせる。
3. 用語リストに無い語は、推測で直さない。直さずに、校正記録の該当フラグへの回答に「不明」を明記する。
4. 意味を変えない。言い回しの好みで書き換えない。
5. 言葉遣いの明らかな誤り（助詞の誤り、欠けた語）だけを直す。
6. 直しは `captions.ass` の本文だけに行う。
7. 時刻（Start と End）と字幕の行数は、変更しない。追加も削除もしない。
8. 1件の字幕の中で言い切れない場合は、その字幕の範囲で収める。範囲を越えた直しはしない。

## 改行

1. 改行（`\N`）は、意味の区切りと文節の切れ目にだけ置く。
2. 1行は16字以内、1件は2行以内に収める。
3. 句読点を行頭に置かない。
4. 改行位置を変えた場合も、校正記録の corrections に本文全体の前後を記録する。

## 検証フラグへの回答

1. `captions.txt` の末尾に並ぶ検証フラグの全件に、回答する。
2. 回答は次のどちらかとする。
   - 直した（corrections に対応する記録があること）
   - そのまま（理由を回答に書くこと）
3. 音があるのに文字起こしが無い区間のフラグは、環境音だけの区間なら「そのまま」とし、その旨を理由に書く。

## 読みやすさの違反への対処

1. `captions.txt` の末尾に並ぶ違反は、本文の修正で解消する。
2. 解消できない違反は、校正記録の waivers に、字幕番号とルールと理由を書いて免除する。
3. 理由の無い免除は認められない。

## 校正記録

1. `work/<jobId>/proof.json` に、次の形で記録を書く。

```json
{
  "planHash": "<captions.json の planHash と同じ値>",
  "checkedFlags": [
    { "flag": "lowConfidence:0", "action": "直した", "note": "根拠を書く" },
    { "flag": "soundGaps:0", "action": "そのまま", "note": "環境音だけの区間" }
  ],
  "corrections": [
    { "cue": 12, "from": "生成時の本文", "to": "校正後の本文", "reason": "同音異義語。前後の文の意味から判断" }
  ],
  "waivers": [
    { "cue": 30, "rule": "cps", "reason": "相槌の短い発話で、表示時間を延ばすと次の字幕と重なる" }
  ]
}
```

2. corrections の from は生成時の本文と、to は校正後の本文と、1文字まで一致させる。
3. 本文を変えた字幕は、全件 corrections に記録する。記録の無い書き換えは認められない。
4. checkedFlags の flag は、`captions.txt` の末尾に並ぶ ID をそのまま書く。

## 照合

1. 次のコマンドで照合する。

```
node src/edit-job.mjs captions <jobId> --check
```

2. 不足が並んだら、該当箇所を直してから、再度照合する。
3. 照合を通ってから、render する。
