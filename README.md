# 動画編集エージェント ai-editor-kit

Claude Code などの AI エージェントに渡して使う、動画編集の仕組み一式です。素材の動画と要望を渡すと、エージェントが文字起こし、編集、字幕付け、検品までを行います。

- **使う人へ**: [`取扱説明書.pdf`](取扱説明書.pdf) を読んでください（A4 1枚）。
- **AI エージェントへ**: セットアップは [`SETUP-CLAUDE.md`](SETUP-CLAUDE.md)、編集の決まりは [`CLAUDE.md`](CLAUDE.md) に従うこと。

## 機能

- ダイジェスト編集: 会話のある動画を文字起こしし、要点の区間だけを選んで1本にまとめます
- 複数素材の組み立て（assemble）: 複数の動画から場面を切り出し、並び替え、テロップを入れて1本にします。縦向きと横向きの混在は、ぼかし背景によるピラーボックスでそろえます
- 複数動画の合算（combine）: 画の寸法と音量をそろえてつなぎ、つなぎ目の検品画像を自動で作ります
- 字幕の生成と校正: 字幕は、全文の校正記録がないと焼き付けできない仕組みです。読みやすさの基準は Netflix 日本語 SDH（1行16字、1秒7字、最大2行）で機械検証します。決まった誤変換は用語辞書で自動修正します
- 境界検品: 全カットの境界画像を自動生成し、頭切れと尻切れを目視で判定する材料を出します
- テンポ計測: PySceneDetect でカット位置を検出し、シーン長の一覧と平均、中央値を出します
- 音の掃除: DeepFilterNet で環境音を抑えた音声を作り、文字起こしの精度を上げます（動画本体の音は元のままです）
- BGM のビート同期: librosa で音楽の拍を取り、場面の切り替わりを拍に合わせます
- 文字起こしの検証材料: 確信度の低い語、句読点だけの語、無音の間を一覧にし、校正で全件に回答する形にします
- 道具のバージョン固定: 使う道具とバージョンは正本で指定し、点検コマンドが実物と照合します

## 必要な環境

- AI エージェント: Claude Code など、ファイル操作とコマンド実行ができるもの
- Node.js 24 系
- Python 3.12 系
- ffmpeg / ffprobe 8.1 系
- Python パッケージ: `video-shorts/requirements.txt` の固定版一式
- 任意: deep-filter 0.5.6（音の掃除を使う場合）

バージョンの正本は `video-shorts/toolchain.json` と `video-shorts/requirements.txt` です。導入後は `node src/edit-job.mjs doctor` で、道具の有無とバージョンの一致を確認してください。

## 導入手順

1. このリポジトリを取得する
2. `cd video-shorts` して、Python パッケージを入れる: `pip install -r requirements.txt`
3. `node src/edit-job.mjs doctor` を実行し、全項目が OK であることを確認する
4. 詳しい段取りは [`SETUP-CLAUDE.md`](SETUP-CLAUDE.md) に従う

## 使い方

最初の1回だけ、このキット一式を AI エージェントに渡します。その後は毎回、次の流れです。

1. 素材の動画を渡す
2. 要望を言葉で伝える（長さ、入れたい場面、BGM の有無など）
3. エージェントが編集して動画を出す
4. 出てきた動画を見て、修正を言葉で指示する（BGM の追加、場面の差し替え、長さの調整、字幕の修正）
5. エージェントが直して出し直す

主なコマンド（エージェントが実行します）:

| コマンド | 役割 |
|---|---|
| `doctor` | 道具とバージョンの点検 |
| `prepare` | 文字起こしと検証材料の作成 |
| `plan` / `approve` | 編集案の作成と承認 |
| `captions` | 字幕の生成と校正の照合 |
| `render` | 動画の書き出し（境界画像つき） |
| `inspect` | 境界画像の作り直し |
| `review` | 目視チェックの材料（代表コマのシートと修正案） |
| `combine` | 複数動画の合算 |
| `assemble` | 複数素材の切り出しと組み立て |
| `tempo` | カット位置とテンポの計測 |

編集の決まり（合格条件、字幕校正の手順、バージョン点検の手順）は `CLAUDE.md` と `docs/` にあります。

## バージョン指定と点検

- 使用できるバージョンは、正本で指定した物だけです。doctor の照合で合わない道具は、失敗として止まります
- AI エージェントが道具を勝手に更新、ダウングレード、代替することは禁止です
- バージョンの点検は月1回です。正本に最終点検日を持ち、30日を過ぎると doctor が点検時期を知らせます。新版はテスト一式を通した場合のみ、正本の指定を書き換えます。手順は `docs/バージョン点検の手順.md` です
