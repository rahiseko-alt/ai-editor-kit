# 動画編集アシスタント（Claude Code 版）

Claude Code のデスクトップアプリで、**チャットに動画を渡すだけ**で、話の要点だけを残したダイジェスト動画を作ります。
AI が文字起こしを読んで「どこを使うか」の台本案を出し、あなたが承認すると書き出します。

- 対応: Windows
- 画面の操作はチャット欄だけです（黒い画面を触る必要はありません）

---

## はじめての準備（最初の1回だけ）

### 1. 必要なソフトを入れる

| ソフト | 入れ方 |
|---|---|
| Claude（デスクトップアプリ） | https://claude.ai/download からダウンロードしてインストールし、ログインする |
| Node.js | https://nodejs.org から「LTS」をダウンロードしてインストール（途中の選択はすべてそのまま） |
| Python | https://www.python.org/downloads/ からダウンロードしてインストール。**最初の画面で「Add python.exe to PATH」にチェックを入れる** |
| ffmpeg | スタートメニューで「ターミナル」を開き、`winget install Gyan.FFmpeg` と入力して Enter（入れたらターミナルは閉じてよい） |

入れ終わったら、PC を一度再起動してください。

### 2. このツールを開く

1. Claude デスクトップアプリを開き、左上の「Code」を選ぶ
2. フォルダを選ぶ画面で、このリポジトリをクローンする（または、ダウンロードして展開したフォルダを選ぶ）
3. チャット欄に **「使えるようにして」** と送る

AI が足りない物を調べて、入れられる物は代わりに入れます。

### 3. 文字起こしのキーを用意する（おすすめ）

文字起こしには、無料で使える Groq のキーを使うと速くなります（キーが無くても動きますが、かなり時間がかかります）。

1. https://console.groq.com にアクセスしてアカウントを作る
2. 「API Keys」→「Create API Key」でキーを作り、コピーする
3. チャット欄に「Groq のキーを設定して」と送り、キーを貼り付ける

キーはこの PC の中（`video-shorts/.env`）にだけ保存され、外に送られることはありません。

---

## 使い方

1. 編集したい動画を、**チャット欄にドラッグ**して「この動画を編集して」と送る
   - 縦型にしたい・字幕を付けたい・「3分くらいに」などの希望があれば一緒に書く（何も書かなければ横型・字幕なし）
2. 文字起こしが終わると、AI が **台本案**（残す部分・捨てる部分）を出します
3. よければ **「承認」**、直したいところがあればそのまま伝える
4. 書き出しと点検が終わると、完成した動画の場所が伝えられます

完成した動画は、このフォルダの中の `.runtime/outputs/` に保存されます。

---

## 困ったとき

チャット欄に、起きたことをそのまま書いてください（例:「エラーが出た」「動画が見つからないと言われた」）。
AI が原因を調べます。
